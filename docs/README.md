# RentEase Documentation

## Purpose

This folder contains project documentation for RentEase, a Django-based rental room / boarding-house management system derived from the old HOSTELLO codebase.

RentEase currently supports a local-demo-ready role-based web application, but it is not production-ready yet.

## Recommended Reading Order

1. `README.md` in the repository root
2. `docs/agent/RENTEASE_PROJECT_MAP.md`
3. `docs/demo/LOCAL_SETUP_AND_DEMO_DATA.md`
4. `docs/RENTEASE-MASTER-TASKS.md`
5. `docs/CHECKLIST-TIEN-DO.md`
6. `docs/spqm/RELEASE_CHECKLIST.md`

## Important Note

The repository still contains legacy HOSTELLO apps and templates. Do not edit legacy files for RentEase UI unless the task explicitly says so.
