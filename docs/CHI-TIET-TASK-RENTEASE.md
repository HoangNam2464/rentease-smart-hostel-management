# Chi Tiết Task RentEase

## Public

- Xem trang chủ RentEase.
- Xem danh sách phòng đang cho thuê.
- Xem chi tiết phòng công khai.
- Gửi đăng ký xem phòng.

## Chủ Trọ

- Xem dashboard vận hành.
- Quản lý phòng.
- Quản lý tin đăng.
- Xem và cập nhật khách thuê đã liên kết.
- Tạo/cập nhật hợp đồng.
- Tạo/cập nhật hóa đơn.
- Ghi nhận thanh toán.
- Xử lý yêu cầu sửa chữa.
- Xử lý đăng ký xem phòng.

## Khách Thuê

- Xem dashboard cá nhân.
- Xem hồ sơ thuê phòng.
- Xem hợp đồng.
- Xem hóa đơn.
- Xem thanh toán.
- Gửi và theo dõi yêu cầu sửa chữa.
- Xem thông báo.

## Quản Trị

- Dùng Django Admin/Jazzmin.
- Xem báo cáo staff-only.

## Lưu Ý

Không hiển thị `citizen_id`, ảnh giấy tờ, mật khẩu, quyền hệ thống hoặc dữ liệu của người khác trên UI không phù hợp.
